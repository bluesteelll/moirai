# Spec sync 3

Changes to `docs/spec/` made in wave 3b for the owner decisions of 2026-10-06 ([m0/PLAN §5] "Owner decisions of
2026-10-06"; `owner-questions.md` OQ-A-5 to OQ-A-10; [AR §11]) and for the items the TencentDB Agent Memory research of
2026-09-30 brought in without an owner question. Each author role appends its own section.
Each row gives:

- **id**: `S3-<role letter>-<n>`, the letter being P (R-SPEC-P), R (R-SPEC-R), F (R-SPEC-F), M (R-MODEL) or X (R-FIX);
- **file §**: the file and the sections changed;
- **change**: what the text now says;
- **source**: the decision (OQ-A-n, with its option) or the TencentDB item, and the finding a row closes;
- **affects**: the code or fixtures that must follow the change, by crate (`moirai-model`, `moirai-format-oracle`,
  `moirai-files`, ...) or fixture directory (`fixtures/<dir>`), or "none". Spec follow-ups by another role are named
  after a semicolon.
