# moirai — архитектура на согласование

Подробное описание архитектуры moirai на русском языке для согласования владельцем перед началом разработки (веха M0).
Оно пересказывает документ-основание [docs/ARCHITECTURE-RESEARCH.md](../ARCHITECTURE-RESEARCH.md) и нормативные документы [40], [50], [60], [80], [90] из [docs/research/design/](../research/design/). При расхождении действует ARCHITECTURE-RESEARCH.md.

Каждый раздел написан по исходникам и затем проверен отдельно: цифры, имена, правила и привязка к вехам. Пометка ⚠ означает расхождение между исходными документами, пометка ✅ — пункт на согласование.

**Состояние на 2026-09-26:** работа не закончена. Разделы 1–7 проверены и исправлены. Разделы 8–15 написаны и проверены, но найденные ошибки ещё не внесены. Сводный чек-лист «что нужно от владельца» ещё собирается.
