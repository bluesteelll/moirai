# moirai — архитектура на согласование

Подробное описание архитектуры moirai на русском языке для согласования владельцем перед началом разработки (веха M0). Оно пересказывает документ-основание [docs/ARCHITECTURE-RESEARCH.md](../ARCHITECTURE-RESEARCH.md) и нормативные документы [40], [50], [60], [80], [90] из [docs/research/design/](../research/design/). При расхождении действует ARCHITECTURE-RESEARCH.md.

Каждый раздел написан по исходникам, затем отдельно проверен (цифры, имена, правила, привязка к вехам), и найденные ошибки исправлены. После этого разделы сверены между собой. 2026-09-27 найденные расхождения исправлены в самих исходных документах (чек-лист, пункт А5). В тот же день вы ответили на чек-лист: А1–А8 приняты как рекомендовано, Б1–Б14 подтверждены, по В1 (LQ-Bench только через подписку Claude Code, без API) и В7 (стенд OS-crash отложен до после релиза) даны ваши решения, В8 принят к сведению; исходные документы приведены к этим ответам. Пометки ⚠ «Расхождение в документах», которые ждали ответов на А1, А2, А3, А6 и А7, сняты; осталась только пометка у Г8, а «⚠ Риск» отмечает принятый риск. Пометка «✅ Подтверждено вами 2026-09-27» или «✅ Решено вами 2026-09-27» — пункт, на который вы ответили; «✅ На согласование» — ресурс или пункт, ответа на который ещё нет; места, где правило выбрала команда дизайна, помечены «решено командой дизайна» (вы приняли их в А5).

Начните с [обзора на одной странице](00-summary.md) и [чек-листа согласования](15-approval-checklist.md): в нём ваши ответы и то, что ещё открыто. AR вместе с [40], [50], [60], [80] и [90] утверждена как спецификация M0 (А4). Открытыми остаются ресурсы на время M0 — В2–В6, В9 и В10 — и пункты Г, которые решаются позже или по условию.
