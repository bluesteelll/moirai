# moirai — архитектура на согласование

Подробное описание архитектуры moirai на русском языке для согласования владельцем перед началом разработки (веха M0). Оно пересказывает документ-основание [docs/ARCHITECTURE-RESEARCH.md](../ARCHITECTURE-RESEARCH.md) и нормативные документы [40], [50], [60], [80], [90] из [docs/research/design/](../research/design/). При расхождении действует ARCHITECTURE-RESEARCH.md.

Каждый раздел написан по исходникам, затем отдельно проверен (цифры, имена, правила, привязка к вехам), и найденные ошибки исправлены. После этого разделы сверены между собой. Пометка ⚠ означает расхождение между исходными документами, пометка ✅ — пункт на согласование.

Начните с [обзора на одной странице](00-summary.md) и [чек-листа согласования](15-approval-checklist.md): в нём всё, что нужно от вас для старта M0.
